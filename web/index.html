Welcome to BugPredictor

A tool that predicts which classes of a software project are likely to contain bugs, so that review and testing time goes where it matters.

Predict the problem before it becomes a problem

ML-powered Bug prediction Genetic algorithm

How it works

  1. Code metricsEach class is described by 20 metrics: size, complexity, coupling, cohesion, inheritance.
  2. A default modelA classifier learns from the classes whose bug history is known.
  3. Genetic algorithmThe GA picks the most useful metrics and tunes the model, generation after generation.
  4. Honest testBoth models are scored on classes kept aside, which the GA never saw.

Everything runs in your browser: pick one of 11 open-source Java projects (PROMISE dataset) or upload your own CSV/ARFF file. Nothing is sent to a server.
